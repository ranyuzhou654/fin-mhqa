## 实现与边界

新增 read_evidence_context，必须从已经观察的 chunk_id 出发。工具启动时核对 ACCEPTED、语料 SHA256 和数量；运行时使用不可变内存快照。按同一公司/源文件/期间读取原表各分段、所在起始物理页、前后物理页或单位声明候选，原样返回带原始 ID 的准入 chunks。每次至多 6 条、24,000 个正文字符，显式 next_cursor；不静默截断原文。不能读取任意路径或任意未见 ID。相邻页不保证同表，声明候选不保证适用，准入 chunks 也不代表完整 PDF 页。

读取占用共享的 8 次工具预算，不增加 search 额度。所有请求、原文响应、错误和最终引用进入轨迹。工具不覆盖原索引单位字段；表内单位优先，适用性仍由模型核对。

预算预留在剩余两次模型调用时，把 Planner schema 限定为 finish（回答或拒答），最后一次给 Verifier。Verifier 不通过仍拒答，绝不跳过验证。沿用 verified 原样发布模式。精度要求写入提示：从原表最精确本期数计算，最后舍入；不把摘要舍入金额当作原始精度。这是提示约束，不是已实现的逐操作数证据证明。

## 2026-09-13：M1 初版，等待数据和 tokenizer 决策

已实现项目包、隔离环境、PDF 文本/表格抽取、保守清洗、按位置遍历章节、连续跨页表格拼接、正文限长切分、表格 Markdown/键值句、去重、命令行入口及人工抽样脚本。

相对文档示例的调整：

- 删除 import 时硬编码加载 bge-m3 的做法，改为显式本地路径且禁止自动下载。
- 数字不再被全局页码正则删除；小数不作为标题。
- 表格按照页面位置归入章节，正文排除表格区域，避免附到页末错误章节。
- 跨页合并加入版面位置和标题/单位一致性条件，支持三页连续表；原始 Page 不被修改。
- chunk ID 按内容与来源确定；去重限制公司、来源、类型，正文数值变化不做模糊去重。
- 表格空单元格保留未知，不凭空复制数值；不自动解释复杂合并表头。
- 表格两种表示均携带完整跨页范围，来源 PDF SHA256 用于溯源。

待真实材料校准的部分：复杂多行合并表头、双栏顺序、无边框表识别；正文短段合并及重叠策略目前保守（同章节缓冲合并，超限封口时最多保留 70 token 尾段，达到目标时不额外复制）；表格按行列而非 token 切分；公司代码暂为空，后续完善公司元数据。章节边界按全部层级切断，比示例的 L3 边界更保守。这些均不宣称已达到设计验收。

验证：运行 `python -m pytest -q` 的离线测试；没有真实 PDF、真实 tokenizer 或 API/GPU 验证。M1 未验收；M2–M8 未开始。

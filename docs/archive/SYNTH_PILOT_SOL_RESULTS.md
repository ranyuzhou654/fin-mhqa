# 内置 Sol 教师生成小样结果

2026-09-13：用户授权后，实际指定内置 `gpt-5.6-sol` 生成30条QA候选。经期间枚举修正、规则复算及主代理源页复核，30条接受为窄范围开发小样。没有调用外部教师API、没有兑换额度重置、没有开始训练。

## 产出与检查

- 23条比较、7条聚合，0条顺序桥接；覆盖10家公司，全部为2025H1营业收入。
- 运算包括差额10、合计6、最大值5、最小值3、极差3、比值百分数2、阈值计数1。
- 初版规则通过0/30，均因期间字段使用“2025年上半年”而非枚举`2025H1`；仅修正该字段后30/30通过。初版、失败记录和定稿分别保留，没有改答案或放宽规则。
- 规则校验覆盖原PDF哈希、chunk归属、原文精确引用、页码、原页数值存在、单位换算、Decimal复算及重复ID/问题；12项测试覆盖数值边界与证据篡改拒绝。
- 主代理实际查看10个引用源页的完整渲染图，并核对全部问题、答案与运算方向。该复核不是独立人工审核或盲审；茅台分解表期间还依靠同报告既有源页事实交叉确认，已记录局限。

阅读入口：[30条逐题审核清单](SYNTH_PILOT_SOL_REVIEW.md)。机器数据及逐项来源审查见 [证据目录清单](../evidence/synth_pilot_sol_v1/manifest.json)。本地原始产出位于 `data/synth/pilot_sol_v1/`；小型JSONL与核验凭据同步保存在Git的`docs/evidence/synth_pilot_sol_v1/`。

## 结果含义

这验证了内置Sol生成、落盘、格式修复与可复核计算链路。30/30只是本批规则通过比例，不是Agent Correctness；生成时允许看到源证据与既有开发标签。没有执行真实检索可达性、独立Judge或收集工具轨迹。

本批单指标、模板化程度高，同一公司/指标组合存在不同运算变体；分组记录在`review.json`，未来不能拆散到训练和测试两边。全部标记`dev_pilot_only`，与既有检索开发证据重叠，不进入Test，也不直接当作SFT工具轨迹。

额度快照由账户级59%到61%，窗口为10080分钟；整数百分比包含主代理、生成代理乃至其他任务，不能据此推导Sol单题token、人民币价格或线性外推全量成本。未取得可归属本批的精确用量账单。

# 长期记忆 v1：文档结构记忆（设计与事先登记）

2026-10-16 写定，任何带记忆的模型运行之前。对应路线图 P5。代码见 [doc_memory.py](../../src/finmhqa/memory/doc_memory.py)、[run_memory.py](../../scripts/run_memory.py)，测试见 [test_doc_memory.py](../../tests/test_doc_memory.py)。

## 为什么先做这一种记忆

[检索指标](RETRIEVAL_METRICS_V1.md)显示，Agent 每题平均检索 2.5–3 次。其中相当一部分花在「找到某公司某张报表在哪」上，而且有些行（如资产负债表的「资产总计」）用标准查询根本召回不到，只能靠读取相邻块绕过去。

这类知识有三个特点：
- **与用户无关**：报告是公开的；
- **不会变**：报告冻结后，表格位置不再变化；
- **可以从已核验的答案里学到**。

所以先做文档结构记忆。另外两种记忆的处理：
- **用户偏好**（单位、小数位、关注的公司）：属于服务层功能，按用户隔离，不影响答题，不做准确率评估；
- **已核验答案缓存**：复用数值需要再次核验原文，风险更高，留到 v2。

## 记什么、怎么写、怎么用

| 环节 | 规则 | 理由 |
| --- | --- | --- |
| 记什么 | 某公司、某报告、某个块里有哪些行名（如「研发费用」），以及块的页码和口径（合并 / 母公司 / 两者）。**只记位置，不记数值** | 数值随题目和期间而变，位置不变；不存数值，就不会把错误数值传给后面的题 |
| 何时写 | 只在答案**通过核验并发布**后，写入它引用的块 | 未通过核验的答案可能用错了表 |
| 写入检查 | 引用的块必须在已准入的索引中，行名从**索引原文**里提取，而不是从这次运行看到的内容里提取 | 被注入的伪造块（如 F3）不在索引中，会被拒绝；被篡改的返回内容（F1、F2）不会进入记忆 |
| 怎么用 | 新问题出现时，按问题里提到的公司、指标名和口径，为每个「公司 × 指标」挑一个最常用的块（优先 Markdown 表），最多 6 个。从索引重新读出原文，作为「已观测的线索」放进 Agent 的初始状态，并说明这些只是线索，期间、口径和单位必须自行核对 | 引用前必须读到原文，这一点照旧成立：线索块就是本次从索引读出的原文，引用它同样要经过核验和发布门禁 |
| 共享范围 | 所有用户共享 | 报告是公开文档 |

**离线预检**：从已有的 B3v2p 无故障运行中学习记忆，再给 Dev 题生成线索。
- 44 道有答案的题中，37 道得到了线索；108 个跳中有 81 个，线索里含有该跳的相关证据；平均每题 2.45 个线索。
- 改用 F2 故障运行来学习记忆，结果几乎相同：79/108。这说明故障运行写入的只是位置。
- 这个预检是在同一批题上学习、又在同一批题上使用，所以是上限。正式评估从空记忆开始。

## 评估（Dev，事先登记）

**运行**：都使用 B3v2p 的冻结配置和同一个运行器，严格串行，每次 50 题。

| 运行 | 说明 |
| --- | --- |
| 对照 | 不用记忆 |
| 正序 | 记忆从空开始，按题号升序答题，边答边写 |
| 逆序 | 记忆从空开始，按题号降序答题 |
| 污染 | 记忆预先从 F2 故障运行（9 月的录制，不另花额度）学习，再按升序答无故障题 |

- 共 200 题次，约 4–5 小时，在 Test 运行全部完成之后进行。
- 对照组与实验组在同一时段运行，避免模型漂移影响比较。

**判定**：

| 编号 | 假设 | 标准 |
| --- | --- | --- |
| H1 | 记忆不降低准确率 | 每题取正序和逆序两次的平均，相对对照的配对差，95% 区间下界 ≥ −5 个百分点 |
| H2 | 记忆减少检索 | 正序与逆序平均每题的检索次数，比对照少 ≥ 20% |
| H3 | 记忆不会传播故障 | 污染运行相对对照的配对差，区间下界 ≥ −5 个百分点 |

**描述性报告**：
- 每题线索数，以及线索的命中情况（线索中是否含有各跳的相关证据）；
- 记忆规模随答题数的增长；
- 输入 token 和模型调用次数；
- 正序和逆序的差异，即题目顺序的影响；
- 线索是否被 Agent 直接引用。

## 已知局限

- **样本**：只有 Dev 50 题，每种运行只跑 1 次。
- **题目重叠**：同一份报告的同一张表会被多道题用到，这正是记忆起作用的前提。真实使用中问题分布更分散，收益可能更小。
- **口径判断靠标题**：口径从表标题和章节路径判断。海尔智家的报表标题只有「二、财务报表」，口径可能误判。这时线索只是多给了一张表，Agent 和核验角色仍要核对口径。

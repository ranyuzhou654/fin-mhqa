实现文档第 5 节要求构建 LangGraph 多跳 Agent，通过本地检索服务受控读取财报证据，保存规划、工具调用、证据和重规划轨迹。M3 验收为固定 20 道手写题（桥接 8、比较 8、聚合 4）：答对至少 8 题，平均工具调用不超过 6 次，无 error 记录，并抽查 5 条轨迹的重规划反馈。

需要确定：教师模型名称、API 服务商（自建服务则提供 base URL），以及可接受的调用额度。凭证应通过本地忽略文件或环境变量配置，不写入 Git 或运行日志。实际预算和调用范围在供应商确定后落实，不把 M3 授权扩展成 M4 批量合成授权。

沿用已确认的证据边界：v1 失败分数保留；v2 是获准修订的开发集标签，不是盲测集。正文短注释与被解释对象的关联、公司/合并口径控制仍需在 Agent 的受控证据读取中处理，不把检索命中率当作多跳答案正确率。

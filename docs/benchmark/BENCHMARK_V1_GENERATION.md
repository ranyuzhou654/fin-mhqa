## 规模与构成

| 题型 | Dev | Test | 模板 |
| --- | ---: | ---: | --- |
| T1 单跳陷阱 | 8 | 16 | 母公司口径（明确写「不是合并口径」）、上年同期或期初、需换算单位或单位不在本表 |
| T2 两公司运算 | 8 | 14 | 差额（保留正负号）、两者之和 |
| T3 条件桥接 | 8 | 14 | 按指标 A 选较高或较低的公司，再查该公司的指标 B |

| T5 三跳及以上 | 12 | 26 | 三家公司排序后算比率、三家合计中的占比、桥接后算增长率 |

另有后备题：Dev 25 道，Test 50 道，按顺序排好。S4 删除某道题时，用同一划分、同一题型的下一道后备题替补，不需要重新划分。

候选池：T1 262、T2 1,515、T3 4,760、T4 181、T5 6,822、T6 240。全部 13,540 道可回答候选，都用 Agent 的计算工具（calculator v2）独立复算过一遍，结果与生成器完全一致。

Test 中 69% 的题至少有一跳证据位于续表，或单位需要从报表其他表头、报告级声明中确定（标签 `hard_location`），超过设计要求的 20%。43% 的题需要换算单位。

## 题面约束

- 题面写明公司、指标、口径、期间、单位和舍入要求；比率和增长率都写明公式。
- 题目 ID 由题面哈希生成（`b1-` 加 10 位十六进制），不含题型，避免 Agent 从 ID 推断出哪道是「无法回答」题。
- 「无法回答」题的前提已在语料中核实：没有任何块提到 2023 年上半年、2025 年第三季度或 2025 全年的数据；所用的 5 家语料外公司（山西汾酒、长城汽车、海信家电、蒙牛乳业、洋河股份）从未出现在语料中。被其他报告提到过的公司（如国轩高科、理想汽车、小米）不使用。

## 划分与防泄漏（固定种子 20260923）

- 按事实组合分组，同一组不跨划分：Test 与 Dev 共享的事实组合为 0。
- **Test 100 道全部含有以往开发题未用过的事实。** 以往开发题（dev20、12 题桥接小样、30 题合成小样）一共用到 22 条台账事实，都是合并口径 2025 年上半年的营业收入、归母净利润、经营现金流净额。
- 同一划分内每条事实最多使用 5 次。原先设为 3 次时，T5 在 Test 中只能凑到 24/26。
- **近似重复**：Test 与 Dev 之间所有题对的字符三元组 Jaccard 都不超过 0.8。这条规则按字面执行：先选定 Test，再选 Dev 时跳过与任何 Test 题过于相似的候选。
  - 副作用：同一模板套用不同公司的「兄弟题」相似度通常超过 0.8，所以 Dev 里没有 T4 比率题（t4_ratio），只有增长率题。Dev 仍通过 T5 的排序加比率题（3 道）练习比率计算和公式定义。
  - 如果希望 Dev 覆盖所有模板，可以把规则改为「Jaccard 超过 0.8 且共享事实才算泄漏」，需要你决定。
